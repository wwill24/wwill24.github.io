# Welcome to my personal website! 

This is my personal website created with Next.js to display my professional experiences, projects, and personal skills

Please visit https://wwill24.github.io/

Or to run it locally:

## Getting started
```bash
git clone https://github.com/wwill24/wwill24.github.io.git
cd personal-website
npm install 
npm run dev
```

Navigate towards http://localhost:3000 on your browser.
